# Habilidades habilitadas para FarmaNorte

Estas habilidades quedan disponibles para el proyecto. Se aplican únicamente
cuando la etapa las necesita.

| Habilidad | Aplicación en FarmaNorte |
|---|---|
| Impeccable | Auditoría y pulido de la interfaz móvil y del panel web. |
| Frontend App Builder / diseño frontend | Construcción de la página web de farmacias en la etapa 3. |
| Playwright | Pruebas reales del panel web, formularios, estados y responsive. |
| Grill-me | Validar decisiones críticas y casos extremos antes de implementarlos. |
| Excalidraw / visualización | Diagramas de arquitectura, flujo de domicilio y estados. |
| Presentaciones | Solo si se necesita una presentación editable del proyecto. |
| Remotion | Solo si se solicita video o material animado; no forma parte del producto. |
| Composio | Solo si se autoriza conectar Gmail, Slack, GitHub u otra herramienta externa. |
| MCP Builder | Solo si se construye un servidor MCP para FarmaNorte. |
| Record & Replay | Convertir un flujo demostrado por el usuario en una prueba o habilidad. |
| Traspaso | Función nativa de Codex para continuar el trabajo en otro chat; no requiere instalación. |

## Regla de uso

La habilidad se aplica antes de modificar la parte correspondiente y la etapa
se vuelve a auditar después de usarla. No se mezclan habilidades de video,
presentaciones o MCP en el código de producción si no son necesarias.
